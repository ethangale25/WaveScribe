VOICE DICTATION
===============

Speak naturally. Type effortlessly.

Voice Dictation is a local, private voice-to-text tool. Your voice never 
leaves your computer - everything is processed locally using AI.


QUICK START
-----------

1. Launch Voice Dictation from the Start Menu or Desktop
2. Wait for the status to show "Ready" (green dot)
3. Open any app where you want to type (Word, Chrome, Notepad, etc.)
4. Press Ctrl+Shift+Space to start recording
5. Speak naturally
6. Press Ctrl+Shift+Space again to stop
7. Your text appears automatically!


FIRST RUN NOTE
--------------

On first launch, the app will download the speech recognition AI model 
(approximately 150 MB). This only happens once. Please be patient and 
ensure you have an internet connection for the initial setup.


FEATURES
--------

* Works in ANY application - anywhere you can type
* 100% local processing - your voice data stays private
* Automatic filler word removal (um, uh, like...)
* Smart capitalization and punctuation
* Customizable hotkey
* Dark and light themes
* Usage statistics


SYSTEM REQUIREMENTS
-------------------

* Windows 10 or Windows 11
* 4 GB RAM minimum (8 GB recommended)
* 500 MB disk space
* Microphone


TROUBLESHOOTING
---------------

App shows "Loading..." for a long time:
  - First run downloads the AI model (~150 MB)
  - Check your internet connection
  - Be patient, it only happens once

Hotkey doesn't work:
  - Make sure no other app uses Ctrl+Shift+Space
  - Try changing the hotkey in Settings

No text appears:
  - Make sure a text field is focused before recording
  - Check that your microphone is working


PRIVACY
-------

Voice Dictation processes all speech locally on your computer. No audio 
data is ever sent to the internet. Your dictations are yours alone.
